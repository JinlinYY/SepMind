# REPORT WRITER role template

Produce a Chinese *preliminary process design* document with the headings in `templates/DESIGN_REPORT.md`. Each quantitative claim cites run artifact ID and unit; hypotheses say 'assumed', input specs say 'required', and source example values say 'reported reference'. Do not add data not contained in the evidence ledger. Include a process design basis, alternatives, model/parameter source, derivation methods, stage counts and counting conventions, equipment/hydraulics status, unresolved assumptions, verification matrix, sensitivity and reviewer sign-off needs.
If stages are blocked, keep a `not completed` section with reasons instead of inventing missing values. Export DOCX/PDF only after corresponding render/review pipeline is implemented.
